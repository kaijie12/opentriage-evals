3 · What comes out
CI quality gate THE MONEY SHOT
GitHub Action runs all suites on every PR, posts a scorecard, and blocks the merge if accuracy drops or false-negatives rise. This is the "SLO / quality gate for AI" every JD wants.
Langfuse dashboard
Every eval run traced; metrics over time, per-slice breakdown. The observability piece most eval portfolios lack — your SRE edge.
Public repo + README
Green CI badge, scorecard table, dashboard screenshot, METHODOLOGY.md. The README is the portfolio page — the link alone makes the case.
↻ The loop that makes it credible: change a prompt → eval re-runs in CI → if it got worse, the gate catches it and the dashboard shows the regression. That caught-a-regression story is the interview.
